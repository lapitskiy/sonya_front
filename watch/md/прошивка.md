# Прошивка часов SONYA-WATCH

Короткая памятка, где лежат данные и как шить без поиска по системе.

## Где что находится

- Проект прошивки: `/home/lapitsky/sonya_front/watch/firmware/sonya_watch`
- ESP-IDF: `/home/lapitsky/esp/esp-idf-5.4.2`
- Скрипт активации окружения: `/home/lapitsky/esp/esp-idf-5.4.2/export.sh`
- `idf.py`: `/home/lapitsky/esp/esp-idf-5.4.2/tools/idf.py`
- Python env ESP-IDF: `/home/lapitsky/.espressif/python_env/idf5.4_py3.10_env`
- Обычно порт часов: `/dev/ttyACM0`

## Быстрая прошивка

```bash
cd /home/lapitsky/sonya_front/watch/firmware/sonya_watch
source /home/lapitsky/esp/esp-idf-5.4.2/export.sh
idf.py --version
idf.py -p /dev/ttyACM0 flash
```

## Проверка монитора

Интерактивный монитор:

```bash
cd /home/lapitsky/sonya_front/watch/firmware/sonya_watch
source /home/lapitsky/esp/esp-idf-5.4.2/export.sh
idf.py -p /dev/ttyACM0 monitor
```

Если интерактивный TTY недоступен, использовать захват в файл:

```bash
cd /home/lapitsky/sonya_front/watch/firmware/sonya_watch
python3 tools/monitor_capture_live.py
```

Файл лога:

- `/home/lapitsky/sonya_front/watch/firmware/sonya_watch/monitor_capture.txt`

## Если `idf.py` не находится

```bash
source /home/lapitsky/esp/esp-idf-5.4.2/export.sh
which idf.py
```

Опционально, чтобы всегда подхватывалось:

```bash
echo 'source /home/lapitsky/esp/esp-idf-5.4.2/export.sh >/dev/null 2>&1' >> ~/.bashrc
```
